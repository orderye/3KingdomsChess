# 三国象棋 · Three Kingdoms Xiangqi

三方象棋 HTML5 单文件游戏。玩家择一方（魏／蜀／吴），另外两方由机器人操作，按规则行棋。

🎮 **在线试玩**：<https://orderye.github.io/3KingdomsChess/>

## 棋盘

13 列 × 10 行 = 130 个交叉点。三方九宫：

| 阵营 | 宫位 | 主公 | 河界 |
|------|------|------|------|
| 魏（曹操，黑） | col 6–8 × row 1–3 | 曹操 | 上河界 |
| 蜀（刘备，红） | col 4–6 × row 8–10 | 刘备 | 下河界 |
| 吴（孙权，绿） | col 8–10 × row 8–10 | 孙权 | 下河界 |

双河界蓝线分隔棋盘为上、中原、下三段。象不得越过任何一条蓝线。

## 行棋顺序

孙权先手，逆时针 **吴 → 魏 → 蜀**。

## 棋子走法

| 棋子 | 走法 |
|------|------|
| 车 | 横竖直线任意格，遇子止 |
| 马 | 一直一斜（日字），蹩腿不可走 |
| 炮 | 横竖直线行进，吃子须恰好隔一子（炮架） |
| 象 | 田字斜二，堵象眼不可走，不得越蓝线 |
| 士 | 宫内斜一格 |
| 主公 | 宫内横竖一格 |
| 兵／卒 | 不可后退；过河前只能前进，过河后可横移，敌底线仅可横走 |
| 勇 | 同兵卒，但过河前即可横移 |

## 特殊规则

- **照面**：两敌主公同列且中间无子，走子方主公即灭。
- **插队应将**：任一方走完后若某方主公被将军，该方立即应将，不占常规顺序；连锁应将继续直到解除。
- **将死 / 困毙**：无合法应将着（将死）或无任何合法走法（困毙）即出局。
- **吴蜀同盟**：蜀吴互不攻击、互不将军，盟约至一方出局或魏灭方解。
- **收编**：蜀或吴出局后，残子（含已翻定随机棋与进位棋）整体移交盟友；已灭方主公转为士随军。魏出局则吴蜀共赢。
- **进位**（每局每方一次）：魏王（折损车／马／炮中两类 → 进位一兵为所缺类型）、昭烈帝（中原置卒面魏行兵之责）、孙大帝（中原置马）。随机棋按翻定类型计入折损；收编所得棋子折损不触发进位。
- **和棋**：同一局面第三次出现，或满 240 着未分胜负。

## 随机棋

6 枚「？」棋开局翻定：

- 绿 ×2 → 魏（兵、马）
- 蓝 ×2 → 蜀（左：炮、卒）／吴（右：炮、勇）
- 黄 ×2 → 掷定后分投蜀（马、卒）与吴（马、勇）

## 棋子编制

按规则文档布阵表逐格落子，全盘共 **43 枚**：魏 19、蜀 12、吴 12。

> ⚠️ 规则文档「编制核对」行称魏 18／蜀 11／吴 11（合计 40），与详细布阵表不符。本实现以布阵表为准。

## 技术栈

纯 HTML + CSS + 原生 JavaScript（IIFE），无第三方依赖，Canvas 2D 渲染，单文件可直接在浏览器中运行。
